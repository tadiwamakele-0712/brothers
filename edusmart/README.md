# EduSmart — Brothers College

School management system for students, teachers, classes, fees, and results.

## Live site

https://tadiwamakele-0712.github.io/brothers/edusmart/

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

## Demo accounts

| Role | Username | Password |
|------|----------|----------|
| Admin | `admin` | `brothers` |
| Teacher | `tmoyo` | `teacher` |
| Parent | `parent` | `parent` |

## Features

- Role-based access (admin only can edit/delete)
- Students, teachers, classes, fees, results
- School about, news, events, activities
- Printable receipts and report cards
- Dark / light mode
- Term fee templates and school logo

Data is stored in the browser (`localStorage`). Use **Reset demo data** on the admin dashboard to restore sample records.
