Lesson 24: Web Accessibility (a11y)

Sites zvinofanira kushanda kune vanhu vese — screen readers, keyboard only, uye low vision. Iyi lesson inobatsira portfolio yako kuita professional.

1. Semantic HTML

✗ Avoid
<div onclick="...">Click me</div>
✓ Use
<button type="button">Click me</button> <nav> ... </nav> <main> ... </main>

2. Images — alt text

<img src="profile.jpg" alt="Tadiwa Makele — web developer" />

Decorative images: alt="" (empty, not missing).

3. Forms — labels

<label for="email">Email</label> <input id="email" type="email" name="email" required />

Every input inofanira kunge ine <label> kana aria-label.

4. Keyboard & focus

Tab kuburikidza ne site — munhu anofanira kuona kuti ari pa element ipi.

/* Usabvisa outline pasina alternative */ :focus-visible { outline: 3px solid #0066cc; outline-offset: 2px; }

5. Color contrast

Text inofanira kunge yakasiyana zvakanyanya ne background (ratio 4.5:1+).

Usaisa color chete kuzivisa error — wedzera icon kana text.

WebAIM Contrast Checker →

6. ARIA (when needed)

<button aria-label="Toggle dark mode">🌙</button> <div role="alert">Message yatambirwa!</div>

Shandisa ARIA kana semantic HTML isingakwanisi — usapindira zvisingodiwa.

8. Quick Lighthouse test

  2. F12 → Lighthouse

  4. Fix issues score inodzikisa
