# Portfolio React (Tadiwa Makele)

React version ye portfolio yako — Lesson 13.

## Install Node.js (rimwe gore chete)

1. Download: https://nodejs.org/ (LTS version)
2. Install uye vhura terminal zvakare

## Run project

```powershell
cd "C:\Users\Tadiwa Makele\Desktop\PROJECT 0712\portfolio-react"
npm install
npm run dev
```

Vhura link inoratidzwa (semu `http://localhost:5173`).

## Build for deploy

```powershell
npm run build
```

Folder `dist/` inobva — unogona ku-deploy pa GitHub Pages.
