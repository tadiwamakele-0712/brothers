Lesson 5 — Responsive Design

Peji Inoshanda Pafoni ne Laptop

Responsive design inoita kuti webhusaiti yako ioneke zvakanaka pane foni, tablet, ne desktop. Unodzidza viewport, flexbox, uye media queries.

Screen yako: — px

1. Viewport Meta Tag

Tag iyi mu <head> inobvumira foni kuratidza peji zvakanaka: 

<meta name="viewport" content="width=device-width, initial-scale=1.0">
  • width=device-width — peji inotora upamhi hwefoni
  • initial-scale=1.0 — zoom pakutanga = 100%

2. Flexbox + flex-wrap

Cards zviri pazasi zvinongedzana mutsara pane laptop. Pafoni, flex-wrap: wrap inoita kuti zvipinde pasi.

3. Media Queries

CSS inochinja kana screen yakaderera. Edza: dzvanya F12 → icon yefoni → shandura saizi. 

@media (max-width: 768px) {
  .hero h1 { font-size: 1.8rem; }
  .project-box { width: 100%; }
}
≤ 480px — Foni diki ≤ 768px — Foni / Tablet > 768px — Laptop / Desktop
