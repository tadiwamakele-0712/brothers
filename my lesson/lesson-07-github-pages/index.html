Mafambiro — Vhura GitHub Pages (5 mins)

  1. Enda ku repo yako pa GitHub
  2. Dzvanya Settings (pamusoro pe repo)
  3. Kuruboshwe, dzvanya Pages
  4. Build and deployment → Source: Deploy from a branch
  5. Branch: main → folder / (root)
  6. Dzvanya Save
  7. Mirira 1–3 minutes — refresh link yako

Kana ukawana 404, mirira 5 minutes. GitHub inotora nguva kuita deploy yekutanga.
