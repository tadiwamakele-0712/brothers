Lesson 6 — Git & GitHub

Chengetedza Kodhi Yako ne Git

Git inochengeta shanduko dzekodhi yako. GitHub inoisa kodhi yako pa internet kuti ugone kugovera uye deploy webhusaiti yako.

Git vs GitHub

Git

Program pa komputa yako — inoteerera shanduko.

GitHub

Website pa internet — inochengeta repo yako online.

Commands Zvakakosha

Dzvanya Copy kuti ukope command:

git status

Ona faira dzakachinja

git add .

Wedzera zvese kune commit

git commit -m "First commit: web projects and lessons"

Chengetedza snapshot

git branch -M main
git remote add origin https://github.com/tadiwamakele-0712/brothers.git
git push -u origin main

Tumira ku GitHub (rimwe gore chete)

Workflow Yezuva Nezuva

1. Edita kodhi → 2. git add . → 3. git commit → 4. git push

First-time setup (rimwe gore)

cd "C:\Users\Tadiwa Makele\Desktop\PROJECT 0712"
